# lol_jinx_kr — 징크스 (League of Legends, 한국어)

리그 오브 레전드 징크스의 한국어 음성을 [CESP v1.0](https://openpeon.com) 이벤트 카테고리에 맞춰 묶은 사운드 팩입니다.

## 설치

```bash
peon packs install lol_jinx_kr
peon packs use lol_jinx_kr
```
